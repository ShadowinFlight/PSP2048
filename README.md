# PSP 2048

PlayStation Portable 自制程序版本的 2048 游戏。基于 PSPSDK / pspdev 工具链开发，使用 GU 硬件 2D 渲染。可在真机（PSP 1000/2000/3000，需自制系统）和 PPSSPP 模拟器（桌面端 / 手机端）运行。

## 功能

- 标准 4×4 棋盘 2048 玩法（移动 / 合并 / 随机生成新方块）
- 开始菜单 → 模式选择 → 游戏的完整流程
- **经典模式**：合成出 2048 即获胜，可选择继续挑战
- **限时模式**：3 分钟内冲击最高分，顶部中央倒计时，剩余 30 秒红色警示，时间耗尽即结算
- 两种模式的最高分**分开记录**并持久化（记忆棒 `ms0:/PSP/SAVEDATA/PSP2048/savedata.bin`）
- 暂停菜单：继续游戏 / 返回主菜单
- **连击系统**：连续产生合成触发连击奖励，连击 3 回合后奖励翻倍
- XMB 菜单封面（PIC1）与图标（ICON0）已内嵌进 EBOOT.PBP
- 标准 2048 配色，8×8 位图字体按位数自动缩放

## 按键说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动方块 / 菜单选项切换 |
| ○ (Circle) | 确认 / 暂停 / 继续 |
| △ (Triangle) | 游戏内一键重启 |

## 游戏模式

### 经典模式

合成出 2048 方块即获胜。胜利后可以继续游戏冲击更高分。

### 限时模式

3 分钟倒计时内尽可能获得最高分。顶部中央实时显示剩余时间，最后 30 秒数字变红提醒。棋盘填满或时间耗尽都会结束本局。

## 连击系统

- 每次移动只要产生合成就算一次连击
- 奖励分 = 基础分（合成值之和） × 本回合合成数
- 连续 **3 回合** 都有合成 → 奖励分 **翻倍**
- 一回合内没有合成 → 连击清零

游戏界面右下角实时显示当前连击与奖励分。

## 编译

前置：安装好 pspdev / PSPSDK，并保证工具链在 `PATH` 中。

```bash
export PATH=$PATH:/home/zhang/pspdev/bin   # 按需修改
cd pspGameDev/PSP2048
make            # 生成 EBOOT.PBP
make clean      # 清理
```

## 运行

- **真机**：将 `EBOOT.PBP` 放入 `PSP/GAME/PSP2048/`，在 PSP 游戏菜单中运行
- **PPSSPP**：直接拖入或"打开"该文件
