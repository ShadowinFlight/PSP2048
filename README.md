# PSP 2048

PlayStation Portable 自制程序版本的 2048 游戏。基于 PSPSDK / pspdev 工具链开发，使用 GU 硬件 2D 渲染。可在真机（PSP 1000/2000/3000，需自制系统）和 PPSSPP 模拟器（桌面端 / 手机端）运行。

## 功能

- 标准 4×4 棋盘 2048 玩法（移动 / 合并 / 随机生成新方块）
- 十字键操控，单方向单次移动不重复合并
- 当前得分 + 最高分实时显示
- **连击系统**：连续产生合成触发连击奖励，连击 3 回合后基础分翻倍
- **本局最高连击**记录，在胜利 / 失败界面展示
- 最高分持久化（记忆棒 `ms0:/PSP/SAVEDATA/PSP2048/savedata.bin`）
- 标题 / 游戏中 / 暂停 / 胜利 / 失败 五种状态界面
- 标准 2048 配色（不同数值不同色块）
- 8×8 位图字体，根据方块位数自动缩放
- 全部按键边沿触发，防抖可靠
- 全局 △ 重启——任何界面一键重来

## 按键说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 方块上 / 下 / 左 / 右移动 |
| ○ (Circle) | 开始游戏 / 暂停 / 继续 / 胜利后继续挑战 |
| △ (Triangle) | **任意界面一键重启** |

## 连击系统

- 每次移动只要产生合成就算一次连击
- 连击累计期间，基础分（合成值之和） × 本回合合成数 = 奖励分
- 连续 **3 回合** 都产生合成 → 奖励分 **翻倍**
- 一回合内**没有合成** → 连击清零

示例：

| 回合 | 合成情况 | combo_streak | 奖励分 |
|------|---------|-------------|--------|
| 1 | 2+2=4 × 2 | 1 | 4×2 = 8 |
| 2 | 2+2=4 × 2 | 2 | 4×2 = 8 |
| 3 | 2+2=4 × 2 | **3** | 4×2×**2** = **16** |

Footer 右下角实时显示连击状态，不同颜色区分基础分和奖励分。

## 编译

前置：安装好 pspdev / PSPSDK，并保证工具链在 `PATH` 中。

```bash
export PATH=$PATH:/home/zhang/pspdev/bin   # 按需修改
cd pspGameDev/2048
make            # 生成 EBOOT.PBP
make clean      # 清理
```

产物：

```
EBOOT.PBP       — PSP 可执行文件，拷到记忆棒即可运行
PARAM.SFO       — 程序信息
psp2048.elf     — 链接后的 ELF（调试用）
```

## 运行

### 真机

将 `EBOOT.PBP` 放入 `PSP/GAME/PSP2048/` 目录，在 PSP 的游戏菜单里选择运行。

### PPSSPP 模拟器

直接把 `EBOOT.PBP` 拖进 PPSSPP，或选择"打开"定位到该文件。

## 技术实现

### 渲染架构

- **GU 2D 管线**：使用 `GU_TRANSFORM_2D` 跳过矩阵变换，顶点直接送光栅化
- **批量渲染**：所有矩形和文字像素整帧累积到静态缓冲，`EndFrame` 一次性提交（减少 GE 命令数、避免真机缓冲复用竞态）
- **GU_SPRITES**：文字渲染使用精灵图元（2 顶点/字符块），替代 `GU_POINTS` —— 兼容手机 PPSSPP 的 GLES 后端（Adreno/Mali 对 `gl_PointSize` 支持有缺陷）
- **非缓存写入**：真机 GE DMA 直接读物理内存，顶点缓冲通过 `0x40000000` 非缓存别名写入（`UNCACHED()` 宏）

### 颜色格式

PSP GU 颜色格式为 `0xAABBGGRR`（R 在低字节），而代码常量沿用网页 2048 的 `0xFFRRGGBB` 写法。通过 `FIXC()` 宏在提交边界统一交换 R/B 通道。

### 真机兼容性

- **不要链接 `-lpspkernel`**：用户态 homebrew 导入内核库（`ThreadManForKernel` 等）会导致真机加载失败（错误码 8002013C，PPSSPP 无此限制）。始终使用 `-lpspuser`
- **阻止 `sceNetInet` 静态导入**：现代 pspsdk 的 libcglue 通过 `__socket_close`/`recv`/`send`/`__set_errno` 拖入网络库 —— 真机未加载网络模块时同样 8002013C。本项目在 `main.c` 中覆盖这四个符号为失败桩

## 已知问题

- 若真机上出现格子显示异常（闪烁、缺失），通常是**缓存一致性**或**缓冲复用竞态**问题 —— 已在最新版本中通过整帧批量渲染 + 非缓存别名写入修复
- PPSSPP 桌面端与手机端 GPU 后端行为差异较大（`GU_POINTS`、缓存模拟），建议以真机表现为最终标准
